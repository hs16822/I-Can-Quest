I CAN QUEST — Forest Edition · V4.2 · Warning Sounds

開始遊玩
1. 下載 I_CAN_QUEST_V4_2.html。
2. 用 Chrome 或 Edge 開啟這個 HTML 檔案，點 START QUEST。
3. 如果下載 ZIP，先解壓縮，再開啟裡面的 HTML。

圖片、森林背景、Fredoka 字型及 Snack Time 背景音樂均已內嵌，無須另匯入素材。
英文朗讀使用裝置提供的 Web Speech 英文語音；第一次使用請先按 Test Voice。
部分系統語音需連網。若該電腦沒有英文語音，可先使用 Visual Challenge。

遊戲設定
• 預設 Visual Challenge、單人、每關 60 秒、Normal 1.0×；分數淘汰制與寶箱／炸彈皆預設開啟。
• 大廳可改為雙人，並可調整每關時間與掉落速度。
• Visual Challenge：看字接圖片／看圖片接單字；雙人各自出題與換題。
• Listening Challenge：聽 I can… 接圖片；雙人共用同一題，兩人都答對才換題。
• 觸控：在各自區域左右拖曳，或按左右箭頭。支援雙點／三點獨立操作。
• 鍵盤：P1 A / D；P2 左右方向鍵。單人也可使用左右方向鍵。
• 接對 +10、接錯 −5（可出現負分）、漏接不扣分；一律不扣時間。
• 每位玩家最多同時 5 個掉落物，生成檢查間隔約 0.85 秒。
• 單人每關目標 50、70、90、110、130；雙人以合計分數達到雙倍目標。
• 共 5 關，時間到才結算。分數淘汰制開啟時，當關達標才晉級；未達標結束冒險。
• 分數淘汰制關閉時，不受分數限制（包括負分），依序玩完 5 關。每關分數重設，總分保留。
• 題庫五個動詞會以隨機不重複的順序輪流出題，輪次交界也避免連續同題。
• 雙人排行榜紀錄各自累積總分；兩人皆會重新輸入名字。
• 排行榜依模式、人數、時間、速度、寶箱／炸彈與淘汰制開關區分，保存在同一瀏覽器。

暫停與全螢幕
• 按暫停或 P 鍵可顯示中央暫停視窗；背景霧化且不能操作。
• 切換分頁、視窗失焦、退出全螢幕會自動暫停。
• 對遊戲區域的長按、右鍵選單、拖拉選取及觸控縮放已做阻擋。
• 作業系統層級的邊緣手勢與實體螢幕的觸控支援仍由設備決定。

前次更新（V4）
• 大廳與瀏覽器標題明確顯示 V4，下載檔名也標示 V4。
• 分數淘汰制、寶箱與炸彈改成設定區最上方的大型 ON／OFF 按鈕。

• 大廳新增「分數淘汰制」與「寶箱與炸彈」兩個獨立開關。
